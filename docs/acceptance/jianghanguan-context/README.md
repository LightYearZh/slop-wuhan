# 江汉关初始视角修正 · 2026-10-29

## 已修正

- 江汉关 OSM 主体为凹形轮廓，邻楼 `osm-building-way-128400513-0` 与其接壤。旧模型主体正确，但各层檐口、屋顶、侧面窗格仍依外接矩形生成，进入凹口和邻楼。现在横向楼层和屋顶均使用真实轮廓三角化，门窗沿真实边界排列；前立面柱列使用真实正立面宽度。移除越界的两个简化四角坡屋顶，保留钟楼。
- 补充数据 `overture-125f76ab-8aa9-461d-9085-4e95e08dd4ad` 的占地约 28 平方米，高约 26.825 米。它处在凹口中，地面多边形去重无法识别，但与专用钟楼上层体积相交。以具体来源 ID 记录为专用模型组件并排除第二次渲染，保留周边建筑；身份移动超出 12 米则中止构建，避免静默误删。
- 日信洋行保留五层及现有来源高度，增加中央浅半圆阳台、上层连续阳台。参考武汉出版社《日信洋行》的建筑描述，细节尺寸为估算，突出控制在约 0.38 米，不扩大碰撞占地。

## 右侧街区的核对结果和未完成事项

- 日清洋行、日信洋行、永利银行和长江航务管理局的 OSM 轮廓均已进入场景，没有在导入阶段整栋遗漏。仅凭截图不能确定标出的灰面是未显示的楼体、低楼屋顶还是空地，仍须对齐同一镜头复核，不能把“源数据存在”当作“画面正确”。
- 日清、日信等有身份依据的历史建筑继续使用历史立面；长江航务管理局不能仅凭邻近关系改成欧式历史建筑。
- 所检查的附近小路在当前 OSM 包中未提供明确的机动车禁行标签，部分仍标记 residential/service。用户现场记忆提示应为小路/步行通道，列为待核对项；本次没有把整片道路改成步行区，也未添加阻挡通行的栏杆。
- 这两项尚未完成实景验收，不声称四处问题全部解决。
