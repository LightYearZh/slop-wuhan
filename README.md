# 武汉漫游 · Slop Wuhan 0.8.4

基于 [Slop Taipei](https://github.com/shwang1979/slop-taipei) 的真实距离漫游。范围扩展为**东西8.06公里、南北6.01公里，48.41平方公里外框（含江面）**。WGS84原点不变，每单位1米；没有压缩街区或改变地标间的距离。

保留江汉路、江汉关与沿江大道，新增两江交汇、龟山、蛇山、黄鹤楼、龟山电视塔、晴川阁，以及武汉长江大桥、晴川桥、江汉桥。不包含全武汉或整个二环，二七滨江与鹦鹉洲大桥留待后续。

## 0.8.4 江汉路街面与历史建筑细化

江汉路新增沿真实步行道走向的青石铺装，区分粗面中线、错缝板材与边带，保留横穿车道和原有孔洞。补交通银行柱廊、汇丰山花、台湾/花旗银行镂空女儿墙、大/小巴公房子收坡屋顶与转角穹顶、美国领事馆八角亭；历史入口增加木门及旧址识别铭牌。调整石材灰度、细微凹凸和窗玻璃变化。总高度与碰撞轮廓不变，细部仍含类型参考和估计，详见[生成方法与资料](docs/HERITAGE_STREET_DETAIL.md)。

## 0.8.3 历史立面补齐与传送状态

历史建筑外观从12栋扩展至22栋，补入交通银行、商业银行（少儿图书馆）、璇宫饭店、华俄道胜银行、新泰、景明、大/小巴公及美俄领事馆旧址。加入石材基座与红砖上层的立面组合；璇宫主体高度按设计单位资料改为28.4m，其余新增建筑保持原高度来源。细部仍为类型参考，不是精确测绘复原。

普通传送保留当前步行、汽车、踏板车或直升机状态；飞行不再被地面入口高度拉低。URL仅在明确给出有效`mode`时切换方式。缩窄桌面窗口也显示操作提示和方式名称，选中方式有固定高亮及按下状态，观景相机增加“返回角色”。验证结束会重新加载正常游玩页，不留下固定镜头或隐藏界面的测试状态。详见[本轮修复与验证](docs/TRAVEL_AND_HERITAGE.md)。

## 0.8.2 门洞与有顶通道

修复铁门关、江汉门、牌坊及廊架被挤出成实心盒子的问题：25处/栋建筑使用分段实体，恢复13段源道路；外观、碰撞、地面铺装和道路图同步开放。地图可搜索或传送到铁门关、江汉门。开口尺寸和屋顶高度仍为显示估计，详见[门洞与架空建筑规则](docs/OPEN_BUILDING_PASSAGES.md)。

## 0.8.1 汉口沿江历史建筑群

按真实OSM身份绑定12栋历史建筑，新增石材拱窗、柱廊、阳台栏杆、檐口与转角圆顶。台湾银行、汇丰、花旗、日清洋行采用照片参考特征；四明、永利和中国实业银行保留简洁近代立面。地图可搜索旧址并传送至附近道路，相机菜单新增“汉口沿江历史建筑群”。构件可复用，单栋参数、资料和估计高度分别记录，详见[汉口历史风貌生成说明](docs/HANKOU_HERITAGE.md)。

## 0.8.0 代表地标与高度筛查

地图加入10处代表地点及安全到达入口，住宅校准楼群不列为核心景点。重做黄鹤楼的折角楼身、交错曲面重檐、回廊、栏杆、宝顶与琉璃瓦；新增红楼专用外观。遍历整个区域生成高度待核对清单，并修订长江中心、万达中心、恒隆商场与绿地中心的高度依据。详见[地标、资料和限制](docs/CORE_LANDMARKS.md)。

## 0.7.1 汉口高层与航运中心体量

修复世纪江尚九栋住宅和恒隆广场办公楼仍为12m占位高度的问题，采用公开建筑资料校正。长江航运中心330m高度得到独立资料印证，保持高度，按原OSM关系成员分离塔楼与低层裙房，并加入示意性的阶梯坡顶。相机菜单新增“长江航运中心与世纪江尚”“世纪江尚住宅楼群”。资料中的设计、封顶和竣工高度存在差异，均记录取舍依据。详见[核对结果](docs/HANKOU_SKYLINE.md)。

## 0.7.0 滨江天际线校正

修复导入遗漏 OSM 建筑部件的问题，恢复33栋建筑内60个有效部件，分别保留裙房和塔楼。校正晴川饭店主楼、积玉桥万达公馆五栋住宅，以及汉口沿江一号北侧办公楼的显示体量；住宅、办公楼和酒店采用不同立面，减少缺乏依据的屋顶水箱与彩钢加盖。楼层换算和照片估计均保留来源标识，尚未完成全区域逐栋高度校准。详见[资料、方法与限制](docs/SKYLINE.md)。

## 0.6.3 干燥路面行驶音效

减弱车辆持续路噪、降低噪声高频成分，低速蠕行不再加入轮胎噪声；松油门时路噪不再接近翻倍。汽车模式的附加行驶风噪降低，保留发动机、环境声及其他载具原有风声。原实现没有雨水或溅水音效，此次调整针对持续噪声容易被听成“轧水”的问题。

## 0.6.2 行道树显示修复

修复树木组已经生成、碰撞已经启用，但未挂接到显示场景的问题。树干与树冠现在正常显示，原有近中远三档细节切换继续生效。新增浏览器回归检查，在沿江大道、中山大道、京汉大道逐棵核对车辆附近40m内的树木位置与实际渲染实例。详见[根因与验证](docs/TREE_VISIBILITY.md)。

## 0.6.1 地面连通与街具碰撞

隧道近地面部分不再强制限宽或生成挡墙，四个口均可向左右地面道路转出；下沉超过0.75m才保留侧向保护。双幅桥面护栏也按相对当地地面的高度裁切，放开贴地连接。花坛、旧式路灯、长椅和停放踏板车的碰撞采用物体形状及朝向，生成时预留的空隙不再当作障碍。详见[修复说明](docs/GROUND_CONNECTIONS.md)。

## 0.6.0 长江隧道

新增武汉长江隧道两条单向主洞，汉口与武昌可以直接驾车往返，每向约3.3公里。保持现有范围和1:1真实水平位置；深度、洞宽、净高及坡度属于显示估算。传送菜单提供“汉口隧道入口”或“武昌隧道入口”（自0.8.3起保留当前方式，驾车穿越时请先选择汽车），地图以虚线标示地下线路。双向均已通过地面道路—隧道—另一岸地面道路的完整车辆物理验证。

复用上海版地下接触与相机规则，保留台北运行系统；修正建筑和桥墩无限延伸到地下的碰撞。暂未加入地下支路、AI隧道车流、轮渡乘船流程。详见[隧道与轮渡调查及实现](docs/TUNNELS.md)。

## 0.5.1修复

移除越过水岸的整块山体覆盖层；两山显示和碰撞统一为25m网格的相同三角面；大桥双幅车道合并为连续可通行桥面，外侧护栏增加碰撞。双向变道跨江、龟山南路上下坡已通过车辆物理验证。详见[修复记录](docs/SURFACE_FIXES.md)。

## 本地运行

需要Node.js 22.12+；生成数据随仓库保存，浏览不需要另行下载。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:4799/ ，旧页面请刷新。生产检查使用 `npm run build`、`npm run preview`，地址 http://127.0.0.1:4187/ 。

- WASD移动，Shift加速，拖动鼠标环顾。
- 1/2/3/4切换步行、汽车、踏板车、直升机；E/Space上升，Q/C下降。
- M打开地图，可搜索黄鹤楼、龟山电视塔、江汉关或路名；顶部“传送”提供安全落点。
- 相机菜单新增黄鹤楼、龟山、长江大桥、两江三镇全景。
- 顶部切换天色，N切换声音，H隐藏界面。

## 数据与局限

普通建筑23,465栋：3,149栋OSM、20,316栋去重后的Overture。4,065段道路适配为9,560条路口间连接；水域约11.38平方公里。保留514条POI、317条交通设施源节点，转换得到154处横道和102组信号控制。街灯、树木和通用立面仍为程序化表现，不是实景设施清单。

新增3D-GloBFP **2020年遥感估计高度**：20,127栋缺高建筑采用严格轮廓匹配后的模型值；已有高度、层数和文献资料优先。仍有2,808栋使用显示估算。模型可能明显低估高楼，不能称为可靠实测楼高；对照结果和处理方法见[扩区记录](docs/CORE_EXPANSION.md)。

公开Terrain Tiles高程用于龟山、蛇山起伏，建筑、道路和玩家共用高度采样。其余低地尚未完整接入DEM；山体边缘、显示高程基准、桥面与坡道仍含估计。黄鹤楼、电视塔、晴川阁是程序化简化外观；江汉关保留。普通历史建筑的汉口专属立面仍待完善。

## 数据重建

Python依赖见requirements.txt。固定湖北PBF放到data/hubei-latest.osm.pbf后：

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
npm run data:build
npm run verify
```

默认config/wuhan-core.json；旧config/wuhan-pilot.json保留。使用 `WUHAN_PROFILE=config/wuhan-pilot.json npm run data:build` 会将生成数据替换为旧试验区。完整回退优先用Git基线。

裁剪后的Overture、3D-GloBFP和高程均已保存。若从原始大包重新裁剪，用 `npm run data:prepare`；下载、校验和与文件位置见扩区记录。普通构建不需要省级高度ZIP。
